This project is an effort to have a curated dataset of recipes, structured and normalized in a way that is useful for Game Development. It's a monorepo consisting of:
- babel, a haskell program that validates and 
- data, a set of scripts/extractors and their outputted python
- mods, where "official" mods for games might exist

# General Principles
- Make Illegal State unrepresentable: ADTs, smart constructors, etc
- Types should mirror the theory of the program
- Fix things in a Pokeyoke way
